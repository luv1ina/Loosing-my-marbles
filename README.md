# ⚪ Losing My Marbles

> *"Is it a marble simulator, or a live broadcast of my mental state during game dev?"*

Welcome to **Losing My Marbles** — an interactive web game where small round objects obey the laws of physics slightly better than the developer who coded them. 

---

## 🕹️ What Is This?

It's a web-based game centered around marble mechanics, spatial navigation, and testing how many times a ball can hit a rigid body before clipping directly into the void.

* **Physics-Driven Gameplay:** Powered by actual math (and a lot of prayers).
* **Smooth Controls:** Designed so you can blame the physics engine, not your hand-eye coordination.
* **Instant Browser Play:** Zero installation required. No 80GB day-one patches here.
* **Custom Assets & Polish:** Built with love, sweat, and mild caffeine poisoning.

---

## 🛠️ Built With

* **Game Engine / Framework:** HTML5 Canvas / JavaScript (or your game engine export of choice)
* **Design & Visuals:** Hand-crafted assets & UI
* **Hosting:** GitHub Pages (because server infrastructure is expensive)
